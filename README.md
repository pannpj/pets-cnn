# Pet Breed Classification with a CNN

## Project goal
This project trains a custom Convolutional Neural Network (CNN) to classify images of 10 cat and dog breeds from the Oxford-IIIT Pet Dataset.

## Planned approach
- Train a CNN built from scratch in PyTorch
- Compare it with a majority-class baseline and logistic-regression baseline
- Use accuracy and macro-F1 as evaluation metrics
- Use a fixed train/validation/test split with seed 42
- Apply augmentation, dropout, weight decay, and early stopping
- Analyze misclassified pet breeds as failure cases

## Dataset
Oxford-IIIT Pet Dataset: https://www.robots.ox.ac.uk/~vgg/data/pets/
